# AI 眼镜原型

用两块小开发板加一台电脑，做出一副能"随问随答、随手拍照录像、连手机蓝牙听歌"的 AI 眼镜原型。

| 操作 | 效果 |
|---|---|
| 手机蓝牙连接 **AI-Glasses** | 眼镜就像蓝牙耳机一样，手机里放什么歌都从眼镜出声 |
| **按住说话**，松手 | 音乐自动暂停；眼镜拍下你眼前的画面并录音，电脑识别后交给大模型看图回答；答完音乐接着放 |
| 说"暂停""继续放""下一首""上一首""大声点""小声点" | 通过蓝牙遥控手机音乐、调节音量 |
| **单击** | 拍照（1600×1200），自动传到电脑相册 |
| **双击** | 开始录像，**再单击**停止，自动传到电脑并转成 MP4 |
| 回答中**按一下** | 停止回答；**按住不放**就直接开始下一次提问 |

所有照片、录像和对话记录，用手机或电脑浏览器打开 `http://电脑IP:8000` 就能看。

## 整体结构：和量产眼镜一样的"双芯片"

```
           眼镜                                         电脑（server.py）
 ┌─────────────────────────────┐   WiFi / HTTP   ┌──────────────────────────────┐
 │ 主控 XIAO ESP32S3 Sense      │ ──录音+照片──▶ │ 语音识别 faster-whisper（本地）│
 │ 摄像头 麦克风 按键 指示灯 SD卡 │ ◀──回答语音─── │ 大模型 Claude / 通义千问 VL 等 │
 └──────────────┬──────────────┘                 │ 语音合成 edge-tts              │
                │ 串口：回答语音、提示音、遥控指令    │ 相册网页                       │
 ┌──────────────┴──────────────┐                 └──────────────────────────────┘
 │ 蓝牙音频板 经典款 ESP32       │ ◀── 蓝牙 A2DP 音乐 / AVRCP 遥控 ──▶ 手机
 │ 功放 + 小喇叭                 │
 └─────────────────────────────┘
```

为什么要两块板：ESP32-S3 有摄像头接口和 PSRAM，但**没有经典蓝牙**，没法当蓝牙耳机；经典款 ESP32 有经典蓝牙，但不适合同时跑摄像头和 WiFi 上传。量产眼镜也是这么分工的：高通 AR1 管拍摄，恒玄 BES2800 管蓝牙和音频。

## 一、准备硬件（约 200–250 元）

| 零件 | 说明 |
|---|---|
| Seeed Studio **XIAO ESP32S3 Sense** | 主控。自带摄像头、数字麦克风、SD 卡槽和 8MB PSRAM，必须是带 Sense 扩展板的版本 |
| **经典款 ESP32** 开发板 | 蓝牙音频板。原型用普通 ESP32-WROOM-32 开发板就行；装进眼镜时换 ESP32-PICO-D4 小板。**不能用 ESP32-S2 / S3 / C3 / C6**，它们没有经典蓝牙 |
| **MAX98357A** I2S 功放模块 | 接在蓝牙音频板上，驱动小喇叭 |
| 小喇叭 8Ω 0.5–1W | 直径 15–20mm 的腔体喇叭，贴在镜腿靠近耳朵的位置 |
| 轻触按键 | 装在镜腿上。调试阶段可以先不接，直接用 XIAO 板上的 BOOT 键 |
| LED + 220Ω 电阻 | 拍摄指示灯，录音、拍照、录像时亮，提醒周围的人 |
| microSD 卡 | 32GB 以内，格式化成 FAT32，录像要用 |
| 3.7V 锂电池 300–500mAh | 做成眼镜时用。原型阶段两块板都插 USB 供电最省事 |

### 接线

**主控 XIAO ESP32S3 ↔ 蓝牙音频板 ESP32**（串口要交叉接）

| XIAO | ESP32 |
|---|---|
| D6（TX） | GPIO16（RX2） |
| D7（RX） | GPIO17（TX2） |
| GND | GND（两块板必须共地） |

**蓝牙音频板 ESP32 ↔ MAX98357A**

| MAX98357A | ESP32 |
|---|---|
| VIN | 3V3 或 5V |
| GND | GND |
| BCLK | GPIO26 |
| LRC | GPIO25 |
| DIN | GPIO22 |
| 输出 + / − | 接喇叭两根线 |

**主控上的按键和指示灯**

| 零件 | 接法 |
|---|---|
| 按键 | 一脚接 D0，另一脚接 GND。接上后把 `config.h` 里的 `BUTTON_PIN` 改成 `1` |
| LED | D4 → 220Ω 电阻 → LED 正极（长脚），LED 负极 → GND |

## 二、电脑端：启动服务器

需要 **Python 3.10 或更新版本**。在 `server` 文件夹里打开终端：

```bash
python -m venv .venv
```

```bash
.venv\Scripts\activate
```

（macOS / Linux 用 `source .venv/bin/activate`）

```bash
pip install -r requirements.txt
```

```bash
copy .env.example .env
```

```bash
python server.py
```

启动后会打印一行 `眼镜 config.h 里的 SERVER_URL 填 http://192.168.x.x:8000`，记下这个地址。

- 第一次启动会自动下载语音识别模型（`small` 约 460MB）。国内下载慢的话，在 `.env` 里打开 `HF_ENDPOINT=https://hf-mirror.com`。
- Windows 弹出防火墙提示时，选择允许"专用网络"，否则眼镜连不上。
- 服务器没有登录验证，只在自己家或自己手机热点的局域网里用。

### 不用硬件先测一遍

服务器开着的时候，另开一个终端（同样先激活 `.venv`）：

```bash
python simulate_glasses.py ask "你好，你是谁"
```

```bash
python simulate_glasses.py ask "这是什么东西" 某张照片.jpg
```

```bash
python simulate_glasses.py ask "下一首" --phone playing
```

回答会存成 `reply.wav`，双击就能听；终端里会打印识别结果、回答和动作（比如 `next`，眼镜收到后会让蓝牙板遥控手机切歌）。然后浏览器打开 `http://localhost:8000` 看对话记录。`simulate_glasses.py photo 照片.jpg` 和 `simulate_glasses.py video 视频.mp4` 可以模拟拍照和录像。

### 选择大模型

改 `.env` 里的 `LLM_PROVIDER`：

| 取值 | 说明 |
|---|---|
| `mock` | 默认值。不调用大模型，只复述听到的话，用来先把硬件和语音链路跑通 |
| `claude` | Anthropic Claude，需要 `ANTHROPIC_API_KEY`，并且网络能访问 Anthropic API。默认模型 `claude-opus-5-5`，推理强度设成 `low`，换回答速度；开启了服务端 fallback，被安全策略拒答时会自动换模型重试 |
| `openai_compat` | 任何兼容 OpenAI 接口的多模态模型，国内网络推荐。`.env.example` 里给了阿里云百炼"通义千问 VL"的写法，豆包、智谱等换掉地址、Key 和模型名即可 |

## 三、烧录两块板的固件

先装好 [Arduino IDE 2](https://www.arduino.cc/en/software)：

1. 文件 → 首选项 → "其他开发板管理器地址"填入：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. 开发板管理器里搜索 `esp32`，安装 **esp32 by Espressif Systems**（3.x 版本，本工程用 3.3.12 编译通过）。

### 蓝牙音频板（经典款 ESP32）

1. 下载 ESP32-A2DP 库：[v1.8.12 源码压缩包](https://github.com/pschatzmann/ESP32-A2DP/archive/refs/tags/v1.8.12.zip)，然后在 Arduino IDE 里选"项目 → 导入库 → 添加 .ZIP 库"。
   **不要安装 arduino-audio-tools**：它是 GPL-3.0 许可证，装了会被自动编进固件（见最后的许可证说明）。编译时出现 `AudioTools library is not included first or installed` 的警告是正常的。
2. 打开 `firmware/audio_hub/audio_hub.ino`。蓝牙名字、引脚、开机音量都在文件开头，一般不用改。
3. 工具菜单里选：
   - 开发板：**ESP32 Dev Module**
   - Partition Scheme：**Huge APP (3MB No OTA/1MB SPIFFS)**（蓝牙协议栈很大，默认分区放不下）
4. 上传。喇叭"嘀"一声就说明启动了。手机蓝牙里搜索 **AI-Glasses** 并连接，放首歌试试。

### 主控（XIAO ESP32S3 Sense）

1. 打开 `firmware/ai_glasses/ai_glasses.ino`，修改同一文件夹里的 `config.h`：WiFi 名称和密码（只支持 2.4GHz），以及 `SERVER_URL`。**不需要装任何库。**
2. 工具菜单里选：
   - 开发板：**XIAO_ESP32S3**
   - PSRAM：**OPI PSRAM**（必须选，否则录音和拍照没有内存）
3. 上传。打开串口监视器（115200），连上 WiFi 后喇叭会再响两声。

### 提示音含义

| 声音 | 含义 |
|---|---|
| 一声"嘀"，接着两声上升 | 蓝牙音频板启动；主控连上 WiFi |
| 短促一声（高） | 开始录音，可以说话了 |
| 很短的"咔" + 一声 | 拍照成功 |
| 两声上升 / 两声下降 | 开始录像 / 停止录像 |
| 一声低沉的长音 | 出错了，看主控串口监视器里的提示 |

## 四、常见问题

**手机搜不到 AI-Glasses**：确认音频板用的是经典款 ESP32（芯片上印着 ESP32-D0WD 之类，不是 S3 / C3），并且分区选了 Huge APP。

**完全没有声音**：声音全部从蓝牙音频板出来。先看音频板开机有没有"嘀"一声：没有就查功放接线；有的话再查两块板之间的串口，TX 和 RX 要交叉接，两块板要共地。主控串口监视器里出现"没收到蓝牙音频板的消息"也是这个原因。

**问答没反应或报错 -1**：`SERVER_URL` 填错、电脑防火墙拦截，或者眼镜和电脑不在同一个 WiFi。用手机浏览器打开 `http://电脑IP:8000/ping`，能看到 `pong` 才说明网络是通的。

**识别不准**：先听听 `server/media/last_question.wav`，这是眼镜最近一次录到的原声。也可以在 `.env` 里换更大的模型 `WHISPER_MODEL=medium`。

**回答慢**：服务器每次都会打印识别、大模型、合成各花了几秒，先看哪一段慢。

**说"放首歌"没反应**：蓝牙只能让手机"播放 / 暂停 / 切歌"，手机上得有个音乐 App 停在播放页面。点名放某首歌做不到，需要以后配合手机 App。

**画面颠倒**：把 `config.h` 里的 `CAMERA_VFLIP` 或 `CAMERA_HMIRROR` 改成 1。

## 五、这个原型和量产眼镜的差距 & 下一步

- **还不能打电话**：音频板现在只做了放音乐（A2DP），没做通话（HFP）。经典款 ESP32 的芯片本身支持，但要改用 ESP-IDF 开发。
- **离不开电脑**：下一步把 `server.py` 部署到云服务器，眼镜连手机热点就能带出门；再下一步做手机 App，替代电脑并负责配网，也能实现点名放歌。
- **按住说话 → 唤醒词**：可以用乐鑫 ESP-SR 的 WakeNet 做"嘿 XX"唤醒（需要改用 ESP-IDF 开发）。
- **延迟**：现在是"整句识别 → 整段回答 → 整段合成"。改成流式识别、流式大模型、边合成边播放，体感能快一半以上。
- **说话时音乐是暂停而不是压低**：量产眼镜一般是把音乐音量压低（ducking），可以在音频板里把音乐和 AI 语音混在一起实现。
- **录像没有声音**：需要录像时同时录麦克风，再在服务器上合成音视频。
- **外形和供电**：3D 打印镜腿，主控和电池放一条腿，音频板和喇叭放另一条腿；两块板共用一块锂电池时要用低压差稳压，注意重量和发热。

## 六、用到的开源项目和许可证

| 组件 | 许可证 | 用在哪里 | 做产品要注意 |
|---|---|---|---|
| 本项目自己的代码（两块板的固件、服务器、模拟脚本） | 没有附带许可证 | 全部 | 由你决定闭源还是开源 |
| arduino-esp32（Arduino 核心） | LGPL-2.1 | 两块板的固件 | 卖产品时要允许用户替换这部分库（通常是提供目标文件）。量产固件一般改用 ESP-IDF（Apache-2.0） |
| esp32-camera | Apache-2.0 | 主控固件 | 保留版权和许可证声明 |
| ESP32-A2DP | Apache-2.0 | 音频板固件 | 保留版权和许可证声明 |
| arduino-audio-tools | GPL-3.0 | **故意没用** | 一旦编进固件，整个固件都要按 GPL 开源 |
| FastAPI / uvicorn / faster-whisper / Whisper 模型 | MIT / BSD-3 / MIT / MIT | 服务器 | 宽松许可证，保留声明即可 |
| anthropic、openai Python SDK | Apache-2.0 | 服务器 | 保留声明即可 |
| imageio-ffmpeg 自带的 ffmpeg 程序 | GPL-3.0（包含 libx264） | 服务器（转码录像） | 只在自己的服务器上运行、不分发给别人，一般不触发开源义务 |
| edge-tts | LGPL-3.0 | 服务器（语音合成） | 它调用的是微软 Edge 浏览器的朗读服务，不是官方开放接口，**不适合商用**。上线前换成正规付费语音合成（阿里云、火山引擎、讯飞、Azure 等） |
| Claude / 通义千问等大模型 API | 各家的服务条款 | 服务器 | 不是开源许可证，按服务条款和计费使用 |

以上按各项目公开的许可证整理，不构成法律意见，量产前请找律师确认。另外，蓝牙产品上市要做蓝牙 SIG 认证，在国内卖无线设备还需要无线电型号核准（SRRC）等认证，这些和软件许可证是两回事。
